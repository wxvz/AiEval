Common questions

Why can train accuracy be 100% but test accuracy 0%?

The network only learned from three corners. It can fit those perfectly while the held-out corner still violates XOR — that is the memorization trap from the read lesson.

What changes if I pick a different test point?

The train set changes. Some splits are easier than others, but the lesson stays the same: always report test performance on rows the model never trained on.

How is this different from the neural network lab?

The neural network lab trains on every puzzle row to focus on loss and weights. This lab enforces an honest train/test split first.
