Common questions

What if retrieval returns the wrong chunks?

Garbage in, garbage out — a wrong context leads to a wrong answer. Test retrieval quality with real prompts in the First evaluation lab or AiEval.

Why a character budget?

Models have a fixed context window. You must rank, trim, or summarize chunks so the prompt fits — the slider simulates that limit.

Why a stub instead of calling a model?

This lab isolates retrieval and prompt assembly without API keys or rate limits. You can see exactly which text reaches the model step.

How do I know if my RAG setup is good?

Run evaluations in AiEval with questions your users actually ask. Compare answers with and without retrieval, and inspect whether the winning answer used the right chunks.
