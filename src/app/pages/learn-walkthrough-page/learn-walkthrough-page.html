Common questions

Do I need to fill in title and prompt?

No for your first run. You can leave them empty and click Run full automation — AiEval will draft a title, prompt, and answers for you.

What does Run full automation do?

It generates answers from multiple models, scores them against the default rubric, picks a winner, and drafts an improved response. This may take a few minutes.

Why is my evaluation highlighted on the dashboard?

Links from this lab include ?from=learn. AiEval highlights your lab evaluation so you can spot it among other evaluations when you return from automation.

What should I look for on Compare?

Read each model answer, check rubric scores per criterion, note which answer won, and ask whether the winner actually meets the criteria you care about.
