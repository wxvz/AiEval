Common questions

Do I need the Acme prompt text from the steps?

Yes for this path. Paste the constrained support prompt and golden questions from the steps so the harness run matches Outside eval practice.

What does Run full automation do?

It generates answers from multiple models, scores them against your rubric, picks a winner and can draft an improved response. This may take a few minutes.

Why is my evaluation highlighted on the dashboard?

After automation finishes from a Learn create link, AiEval stores a handoff in this browser session and highlights that evaluation. The dashboard banner's Compare link opens it.

When can I mark the lab complete?

After this lab has recorded a handoff evaluation (run automation from the create steps with the Learn links). Then return here and mark complete.

What should I look for on Compare?

Read each model answer, check rubric scores per criterion, note which answer won and ask whether the winner actually meets the criteria you care about.

What counts as a ship decision?

One sentence that cites a rubric row, for example which model wins Faithfulness on the price case or why neither is safe to ship yet.
