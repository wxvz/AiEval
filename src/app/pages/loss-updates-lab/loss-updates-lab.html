Common questions

Why does loss wiggle instead of falling smoothly?

Each epoch is one pass through four XOR rows. Small networks and a high learning rate can overshoot — that is normal in the teaching sandbox.

What should I try if loss stays flat?

Adjust the learning rate slider and reset. Too small crawls; too large bounces. This is the same knob from the read lesson.
