Common questions

Why can a private boot outrank the right product?

Similarity measures relatedness, not permission. Without a tenant filter, a visually similar private record can beat an authorized match, so trusted metadata filters must run in application code.

Why compare image queries to image vectors?

This lab uses one shared multimodal space, but still matches query modality to the stored vector for that media. Mixing unrelated embedding models just because they share a length would break ranking.

Is a high score enough to ship an answer?

No. Score retrieval first (did the right evidence appear?), then judge whether a generated answer stays faithful to those records. Fluency alone can hide a bad candidate set.
