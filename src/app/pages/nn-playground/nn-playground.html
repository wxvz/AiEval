Neural networks

A neural network is a small program that learns from examples, like studying flash cards. You show it two numbers, tell it the right answer and it tries to guess. When it is wrong, it makes a small correction and tries again.

Common questions

Why is AND dataset easier?

AND is easier because one straight boundary can separate the outputs: only [1, 1] maps to 1, while the other points map to 0. XOR needs a curved split, which is why it usually needs a hidden layer.

What is sigmoid?

Sigmoid is an activation function that squeezes any input into a value between 0 and 1. It is useful when outputs are binary-like or probability-like.

What is a hidden layer?

A hidden layer is the middle layer between inputs and outputs. It helps the network combine inputs in more flexible ways, so it can learn patterns that a single layer cannot.

When should I use softmax?

Use softmax when you have several classes and want the network to pick one (probabilities that add up to 100%). This page uses 3 classes. For a single yes/no answer, use sigmoid instead.
