Common questions

Why not use linear everywhere?

Linear keeps the score unchanged. Stacking linear layers is still one linear map, so the network cannot learn curved boundaries. Non-linear activations break that collapse.

When is sigmoid a good default?

At a binary-style output, when you want values in (0, 1). In hidden layers it can flatten large scores and slow learning, so ReLU is often preferred there.

What does ReLU “silence” mean?

For negative z, ReLU outputs exactly 0, so that unit contributes nothing on that example. Positive scores pass through unchanged.
