About AiEval

AiEval helps you compare AI model answers against a rubric, pick a winner, and draft an improved response.

  • Create evaluations with prompts and answers
  • Score answers with a rubric table
  • Mark a winner and capture an improved answer

How to add rubric criteria

  1. Open an evaluation from the dashboard and go to Edit.
  2. In the Rubric criteria section, enter a criterion name (e.g. Accuracy), an optional description of what a strong score looks like, and the max points for that row.
  3. Example: Accuracy, Clarity, Completeness, Relevance, Safety, etc.
  4. Click Add criterion. Repeat for each row you want in your rubric.
  5. Add model answers in the right column, then open Compare to view the rubric table and mark a winner.

How to add model answers

  1. Open an evaluation from the dashboard and go to Edit.
  2. In the Answers section, enter a model name (e.g. GPT-4) and the model answer.
  3. Click Add model answer. Repeat for each model answer you want to compare.
  4. Open Compare to view the rubric table and mark a winner.

How to make an improved answer

  1. Read all answers.
  2. Score them using your rubric.
  3. Pick the best answer.
  4. Look at what the best answer still lacks.
  5. Borrow good parts from other answers if useful.
  6. Remove weak parts, confusing wording, or incorrect claims.
  7. Rewrite the final answer in your own cleaner version.
  8. Open an evaluation from the dashboard and go to Improved.
  9. Fill in Winning answer, What was good about it?, What was missing or weak?, Useful parts from other answers, and Improved final answer, then click Save improved answer.
